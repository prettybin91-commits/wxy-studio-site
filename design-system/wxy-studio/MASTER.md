# WXY STUDIO — Kinetic Atelier Design System

## 브랜드 방향
검정 무대 위에서 문제를 선명하게 드러내고, 청록색 한 번의 개입으로 구매 결정을 움직이는 전환 설계 스튜디오.

## 디자인 언어
- 검정색 설득 장면과 따뜻한 아이보리 증거 장면을 강하게 교차한다.
- 장식 이미지 대신 대형 문장, 코드형 라벨, 작업 화면의 비율을 시각적 재료로 쓴다.
- 청록은 CTA·선택 상태·핵심 단어 중 하나에만 집중하고, 핑크는 순간적인 모션 흔적으로만 쓴다.
- 비대칭 편집 그리드와 넓은 공백으로 기술적 정밀함과 인간적인 표현을 함께 보여준다.

## 색상
| 역할 | Hex | OKLCH | 사용 |
|---|---|---|---|
| Ink | `#000000` | `oklch(0 0 0)` | HERO, 설득, 프로세스 |
| Paper | `#FAFAF8` | `oklch(0.985 0.003 106)` | 증거, 서비스, 포트폴리오 |
| Signal | `#0FD6D9` | `oklch(0.796 0.135 197)` | CTA 테두리, 활성 상태, 표현형 단어 |
| Signal pale | `#EDFEFD` | `oklch(0.986 0.018 194)` | 주요 CTA 배경 |
| Pulse | `#FF30D9` | `oklch(0.689 0.293 334)` | 짧은 모션 흔적 |
| Focus | `#00A3FF` | `oklch(0.691 0.174 241)` | 키보드 포커스 |
| Muted | `#9F9F9F` | `oklch(0.693 0 0)` | 보조 정보 |

본문은 다크에서 `#CFCFCF/#000000`, 라이트에서 `#555555/#FAFAF8`를 사용한다. 주요 CTA는 `#000000/#EDFEFD`로 WCAG AA를 충분히 통과한다.

## 타이포그래피
- 한글 산세리프: `Noto Sans KR`, 400–900.
- 영문 산세리프: `Open Sans`, 400–800.
- 표현형 강조: `Cormorant Garamond Italic`; 한글 폴백은 `Gowun Batang`.
- 코드·좌표: `Source Code Pro`, 500–700.
- 모든 본문과 제목의 기본 행간은 글자 크기의 `1.22`.
- Display: `38–84px`, 800, 자간 `-.055em`.
- Section title: `32–64px`, 800, 자간 `-.055em`.
- Body: `15–18px`, 400–600.
- Label: `10–12px`, 600, 자간 `.08–.16em`.
- 표현형 서체는 한 문장 전체가 아니라 핵심 단어 한 덩어리에만 사용한다.

## 간격과 그리드
- 기본 단위: 8px.
- 거터: 375px `20px`, 768px `48px`, 1024px 이상 `64px`.
- 최대 폭: `1360px`.
- 섹션 간격: 모바일 `96px`, 태블릿 이상 `140px`.
- 본문 행 길이는 약 620–720px로 제한한다.
- 데스크톱은 5/7 또는 4/8 비대칭 분할, 모바일은 DOM 순서 그대로 단일 열을 사용한다.

## 컴포넌트
- 버튼: 높이 42–56px, 반경 8px, 청록 테두리와 옅은 청록 면. 눌림만 `scale(.97)`.
- 카드: 반경 8px 이하. 그림자 대신 1px 선과 배경 대비로 구분한다.
- 프로세스: 108–112px 이상의 세로형 박스를 한 열로 쌓고 번호·제목·더보기 아이콘을 정렬한다.
- 입력창: 높이 52px 이상, 항상 보이는 라벨, 검정 면과 청록/블루 포커스.
- 내비게이션: 76px 고정 헤더, 얇은 하단선, 모바일 실제 토글 버튼과 `aria-expanded`.
- 모달: Escape와 바깥 클릭으로 닫고, 열린 직후 닫기 버튼에 포커스를 둔다.

## 이미지와 작업물
- 실제 작업물은 큰 화면 비율로 보여주고 제목은 이미지 아래에 둔다.
- 임시 작업물은 UI 구조가 읽히는 색면으로 제작하며 레퍼런스의 작품이나 로고를 복제하지 않는다.
- 포트폴리오와 후기는 연속 레일로 흐르며 hover/focus에서 멈추고 감소 모션에서는 수동 가로 스크롤로 바뀐다.

## HERO Stage
- Preset: `flat-blank`.
- 배경: 순수 검정, 별도 이미지나 그라디언트 없음.
- 주인공: 중앙 정렬된 3단 타이포그래피 조합.
- 관계: `composition + flat`.
- 청록 표현형 단어와 가장자리의 희미한 코드 문장이 시각적 긴장을 만든다.

## 반응형
- 375px: 38px HERO, 단일 열, 20px 거터, 레일 카드 78–80vw.
- 768px: 2열 증거·서비스·폼, 48px 거터.
- 1024px: 좌측 서비스 탭 고정, 비대칭 그리드, 64px 이상 거터.
- 1440px: 최대 1360px 안에서 공백만 확대하며 본문 폭은 유지한다.

## 모션
- 기능 반응 150ms, 컴포넌트 220ms, 내러티브 600–900ms.
- easing: `cubic-bezier(.4,0,.2,1)`.
- 자동 레일은 hover에서 정지한다.
- `prefers-reduced-motion`에서는 모든 루프·이동·부드러운 스크롤을 제거한다.

## 금지
- 장식용 네온 그라디언트와 빛 리본.
- 모든 콘텐츠를 둥근 카드에 넣는 구성.
- 청록·핑크·블루를 한 요소에 동시에 사용하는 것.
- 의미 없는 3D 오브젝트 또는 레퍼런스 자산 복제.
- 한 섹션에 경쟁하는 CTA 두 개 이상.
- `transition: all`, hover 전용 정보, 감소 모션 대체가 없는 자동 이동.
